# sparrow-studio

A browser workspace for preparing shapes and nesting irregular parts with [sparrow](https://github.com/JeroenGar/sparrow). Files and nesting calculations stay on your device.

The application lives in `web/`. See [build, development and testing instructions](web/README.md). Design notes and prior acceptance records live in `notes/`.

This prototype was developed separately from the original sparroWASM wrapper. It has not been deployed. The repository retains its MPL-2.0 license and bundled third-party notices.
