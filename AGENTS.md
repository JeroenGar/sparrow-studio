# Rules for agents

## Sparrow Pro stays behind its API

This repository is public. Sparrow Pro, the hosted solver, is closed source, and only two parts of it belong here: the job format (`vendor/sparrow-pro-schema`) and the API (`vendor/openapi.json`, with its contract).

- Never put anything from Sparrow Pro's optimizer, its other crates, or its internal documents into code, comments, tests, commit messages, pull request descriptions, or issues here: no algorithms, heuristics, parameters, internal names, or descriptions of how it solves a job.
- Describe Sparrow Pro only by what its schema and API say it does, as any API client would.
- Open-source sparrow is public; its internals may be discussed freely.
- `vendor/` is generated by a workflow in Sparrow Pro. Never edit it here.
